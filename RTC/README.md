
##  What is RTC?

**RTC (Real-Time Clock)** is used to keep track of **current time and date**.

Works even when system is OFF (with battery)

---

## Why RTC is Used?

- Time tracking  
- Data logging  
- Scheduling tasks  

---

## How it Works

- RTC runs using a **small battery**
- Keeps counting time continuously

---

##  Common RTC Modules

- DS1307  
- DS3231  

---

##  Basic Connection (I2C)

- VCC → Power  
- GND → Ground  
- SDA → Data  
- SCL → Clock
